# Development roadmap

Implemented foundations: strict shared context schema, local CLI and Git evidence collection, generic transcript normalization, OpenAI-compatible backend adapter, VS Code command foundation, and Chrome MV3 capture/download foundation.

Remaining before a production deployment: authentication and durable distributed rate limiting for the API, provider-specific structured-output conformance testing, signed extension packaging, robust diff/path edge-case coverage, opt-in artifact attachment UX, and confirmed versioned adapters for any Codex or Claude Code export formats. There is no MCP integration by design.
